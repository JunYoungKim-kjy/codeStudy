# 2강 · 문자열과 숫자, 자료형 바꾸기

**목표:** 문자열과 정수의 차이를 설명하고, 필요한 경우 `int()`와 `str()`로 값을 바꿀 수 있다. 예상 시간은 30~40분이다. 오늘도 긴 프로그램을 만들지 않는다.

## 1. 지난 수업 복습

```python
print("20" + "3")  # 203
print(20 + 3)      # 23
```

문자열끼리 `+`를 쓰면 글자를 **이어 붙인 새 문자열**이 만들어진다. 정수끼리 `+`를 쓰면 숫자를 더한다. 문자열은 순서가 있는 글자들의 모음이지만, 여기서는 리스트나 배열에 값을 추가하는 과정으로 생각하지 않아도 된다.

`"20" + 3`처럼 문자열과 정수를 바로 더하면 `TypeError`가 난다. Python은 어느 쪽 결과를 원하는지 임의로 결정하지 않는다.

## 2. 자료형 확인하기

```python
print(type("20"))  # <class 'str'>
print(type(20))    # <class 'int'>
```

`type()`은 값의 자료형을 알려준다. `str`은 문자열, `int`는 정수다. 출력에 보이는 `class`라는 단어는 지금 외우지 않아도 된다.

## 3. 원하는 자료형으로 바꾸기

**숫자로 계산하고 싶을 때:**

```python
price = "2500"
quantity = 2
print(int(price) * quantity)  # 5000
```

`int("2500")`은 숫자로 읽을 수 있는 문자열을 정수 `2500`으로 바꾼다.

**글자를 이어 붙이고 싶을 때:**

```python
day = 3
print("공부 " + str(day) + "일째")  # 공부 3일째
```

`str(3)`은 정수 `3`을 문자열 `"3"`으로 바꾼다.

`int("사과")`는 숫자로 읽을 수 없으므로 `ValueError`가 난다. 변환 함수도 모든 값을 바꿀 수 있는 것은 아니다.

## 4. 먼저 예상하기

실행하기 전에 출력 또는 오류를 예상하고, 이유를 한 문장씩 적어 본다.

```python
print("7" + "2")
print(int("7") + 2)
print("7" + str(2))
```

추가로 이 코드의 마지막 출력도 예상해 본다.

```python
score = "10"
score = int(score) + 5
print(score)
```
