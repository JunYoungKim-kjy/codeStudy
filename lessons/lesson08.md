# 8강 · 딕셔너리와 집합

**목표:** 키와 값으로 데이터를 관리하는 딕셔너리와 중복을 제거하는 집합을 이해하고, 상황에 맞는 자료구조를 선택한다.

이번 강의는 학생 점수, 단어 빈도, 공통 항목처럼 실제로 자주 만나는 데이터를 직접 코드로 표현하는 방식으로 진행한다. 문제는 완성 코드를 복사하지 않고 요구사항을 읽은 뒤 직접 작성한다.

## 0. 어떤 자료구조를 선택할까?

자료의 목적에 따라 자료구조를 선택한다.

- 순서대로 여러 값을 저장하고 위치로 접근: 리스트
- 이름표를 붙여 값을 찾기: 딕셔너리
- 중복을 없애고 포함 여부나 집합 관계 확인: 집합

예를 들어 학생 이름과 점수를 연결하려면 딕셔너리가 편하고, 두 반의 공통 학생을 찾으려면 집합이 편하다.

## 1. 딕셔너리 만들기

딕셔너리는 키와 값의 쌍으로 만든다.

```python
scores = {
    "민수": 80,
    "지영": 95,
    "철수": 70,
}
```

여기서 `"민수"`는 키이고 `80`은 값이다. 키를 사용해 값을 찾는다.

```python
print(scores["민수"])
```

리스트가 위치를 기준으로 찾는다면 딕셔너리는 키를 기준으로 찾는다.

## 2. 값 추가와 수정

새 키에 값을 대입하면 항목이 추가되고, 이미 있는 키에 대입하면 값이 수정된다.

```python
scores["현우"] = 88
scores["민수"] = 85
```

실행 후에는 현우가 추가되고 민수의 점수가 85로 바뀐다.

키는 하나의 딕셔너리 안에서 중복될 수 없다. 같은 키에 다시 값을 넣으면 기존 값이 새 값으로 바뀐다.

## 3. 키가 있는지 확인하기

없는 키를 대괄호로 조회하면 `KeyError`가 발생한다.

```python
# print(scores["없는 사람"])  # 오류
```

조회 전에 `in`으로 키의 존재 여부를 확인할 수 있다.

```python
name = "민수"

if name in scores:
    print(scores[name])
else:
    print("점수가 없습니다.")
```

`get()`을 사용하면 키가 없을 때 기본값을 줄 수 있다.

```python
score = scores.get("없는 사람", 0)
print(score)
```

`get()`의 기본값은 실제 점수가 0점인 경우와 키가 없는 경우를 구분해야 할 때 주의해서 사용한다.

## 4. `keys`, `values`, `items`

딕셔너리의 키, 값, 키와 값의 쌍을 순회할 수 있다.

```python
scores = {"민수": 80, "지영": 95, "철수": 70}

for name in scores.keys():
    print(name)

for score in scores.values():
    print(score)

for name, score in scores.items():
    print(f"{name}: {score}")
```

실제로는 딕셔너리를 직접 순회해도 키를 하나씩 얻는다.

```python
for name in scores:
    print(name)
```

키와 값을 함께 사용해야 할 때는 `items()`가 읽기 쉽다.

## 5. 딕셔너리 삭제

`del`이나 `pop()`으로 항목을 삭제할 수 있다.

```python
scores = {"민수": 80, "지영": 95}

del scores["민수"]
```

`pop()`은 삭제한 값을 반환한다.

```python
score = scores.pop("지영")
print(score)
```

없는 키를 삭제하면 오류가 발생할 수 있으므로, 삭제 전에 `in`을 사용하거나 `pop(key, default)`를 활용한다.

## 6. 단어 빈도 세기

딕셔너리는 항목별 개수를 세는 데 자주 사용한다.

```python
words = ["apple", "banana", "apple"]
counts = {}

for word in words:
    if word not in counts:
        counts[word] = 0
    counts[word] += 1

print(counts)
```

처음 본 단어는 0으로 준비하고, 볼 때마다 1씩 증가시킨다.

## 7. 집합 만들기

집합은 중복을 허용하지 않는다.

```python
numbers = {1, 2, 2, 3, 3}
print(numbers)
```

출력에는 1, 2, 3만 남는다. 집합은 순서를 기준으로 사용하는 자료구조가 아니므로 출력 순서를 예측하지 않는다.

빈 집합은 `{}`가 아니라 `set()`으로 만든다.

```python
empty_set = set()
empty_dict = {}
```

`{}`는 빈 딕셔너리다.

## 8. 집합에 추가와 삭제

```python
colors = {"red", "blue"}

colors.add("green")
colors.discard("yellow")
```

- `add(value)`: 값을 추가
- `discard(value)`: 값이 없어도 오류 없이 삭제
- `remove(value)`: 값이 없으면 오류 발생

없는 값일 수 있다면 `discard()`가 안전하다.

## 9. 집합 연산

두 집합의 관계를 연산으로 확인할 수 있다.

```python
first = {"민수", "지영", "철수"}
second = {"철수", "현우", "영희"}

print(first & second)  # 교집합
print(first | second)  # 합집합
print(first - second)  # 차집합
```

- `&`: 양쪽에 모두 있는 값
- `|`: 양쪽의 모든 값
- `-`: 왼쪽에만 있는 값

결과 집합의 출력 순서는 고정된 순서라고 가정하지 않는다.

## 10. 딕셔너리와 집합을 함수로 다루기

앞 강의에서 배운 함수와 결합할 수 있다.

```python
def count_words(words):
    counts = {}

    for word in words:
        counts[word] = counts.get(word, 0) + 1

    return counts
```

함수는 빈도표를 반환하고, 출력은 바깥 코드에서 담당한다.

```python
result = count_words(["a", "b", "a"])
print(result)
```

## 11. 자주 하는 실수

### 딕셔너리의 키와 값을 뒤집음

`student["민수"]`처럼 대괄호 안에는 찾고 싶은 키를 넣는다.

### 없는 키를 바로 조회함

키가 항상 있다고 보장되지 않으면 `in`이나 `get()`을 사용한다.

### 빈 딕셔너리와 빈 집합을 혼동함

`{}`는 빈 딕셔너리이고, 빈 집합은 `set()`이다.

### 집합의 출력 순서를 기대함

집합은 중복 제거와 포함 여부 확인에 사용하고, 순서가 필요하면 리스트를 사용한다.

### 리스트로 빈도를 계속 검색함

항목별 개수를 많이 세어야 한다면 매번 리스트를 처음부터 찾기보다 딕셔너리에 개수를 저장한다.

## 12. 직접 작성하는 연습 문제

아래 문제는 완성 코드를 제공하지 않는다. 자료구조를 먼저 선택하고, 함수의 입력과 반환값을 정한 뒤 직접 작성한다.

### 문제 1 · 학생 점수 조회

학생 이름과 점수가 담긴 딕셔너리를 만든다. 이름 하나를 입력받아 점수를 출력하고, 이름이 없으면 “점수가 없습니다.”를 출력한다. 없는 키에서 오류가 발생하지 않도록 처리한다.

### 문제 2 · 점수 추가와 수정

학생 점수 딕셔너리에 새 학생을 추가하고 기존 학생의 점수를 수정한다. 수정 전후 딕셔너리의 내용을 출력해 차이를 확인한다.

### 문제 3 · 평균 이상 학생

학생별 점수가 담긴 딕셔너리를 받아 전체 평균을 계산하고, 평균 이상인 학생 이름만 새 리스트에 담아 반환하는 함수를 만든다.

### 문제 4 · 단어 빈도표

문자열 리스트를 받아 각 단어가 몇 번 나왔는지 세는 함수를 만든다. `get()`을 사용해 처음 등장한 단어도 처리한다.

### 문제 5 · 중복 제거

중복된 숫자가 들어 있는 리스트를 받아 중복이 제거된 집합을 반환하는 함수를 만든다. 집합의 출력 순서가 입력 순서와 다를 수 있다는 점을 확인한다.

### 문제 6 · 공통 학생 찾기

두 반의 학생 이름 리스트를 받아 두 반에 모두 속한 학생을 집합으로 반환하는 함수를 만든다. 교집합 연산을 사용한다.

### 문제 7 · 한쪽 반에만 있는 학생

두 학생 집합을 받아 첫 번째 반에만 있는 학생을 반환하는 함수를 만든다. 차집합 연산을 사용한다.

### 문제 8 · 안전한 딕셔너리 삭제

딕셔너리와 삭제할 키를 받아 해당 키가 있으면 값을 삭제하고, 없으면 오류 없이 원래 딕셔너리를 반환하는 함수를 만든다. `pop()`의 기본값이나 `in`을 사용한다.

### 문제 9 · 함수 조합

단어 리스트를 받아 빈도표를 만들고, 빈도수가 2 이상인 단어만 집합으로 반환하는 함수를 만든다. 빈도 계산 함수와 조건 필터 함수를 분리해도 된다.
