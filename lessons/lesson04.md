# 4강 · 반복문 기초

**목표:** 같은 작업을 여러 번 수행할 때 반복문을 사용하고, 반복이 언제 시작되고 끝나는지 추적한다. 이번 강의에서는 `for`, `range`, `while`를 익힌다.

이번 강의는 결과를 손으로 먼저 따라가고 그다음 실행하는 방식으로 진행한다. 반복 변수의 값과 종료 조건을 확인하는 것이 핵심이다.

## 0. 지난 강의와 연결하기

3강에서 배운 조건문은 조건에 따라 실행할 코드를 선택했다. 반복문은 코드를 여러 번 실행한다. `while` 반복문은 조건문과 같은 비교식으로 계속할지 멈출지 결정한다.

## 1. 목록의 값을 하나씩 꺼내기: for

목록에 든 값을 차례로 처리할 때 `for`를 사용한다.

~~~python
fruits = ["사과", "바나나", "포도"]

for fruit in fruits:
    print(fruit)
~~~

실행 흐름은 다음과 같다.

1. 첫 번째 반복에서 `fruit`에 "사과"를 넣고 출력한다.
2. 다음 반복에서 `fruit`에 "바나나"를 넣고 출력한다.
3. 다음 반복에서 `fruit`에 "포도"를 넣고 출력한다.
4. 더 가져올 값이 없으면 반복을 끝낸다.

`fruit`는 반복 변수다. 이름은 자유롭게 정할 수 있지만, 반복 중인 값의 의미를 드러내는 이름을 쓰면 읽기 쉽다.

## 2. 정해진 횟수만큼 반복하기: range

`range`는 반복할 숫자의 범위를 만든다.

~~~python
for number in range(5):
    print(number)
~~~

출력은 0, 1, 2, 3, 4다. `range(5)`는 0부터 시작하고, 끝 숫자 5는 포함하지 않는다.

시작 숫자도 지정할 수 있다.

~~~python
for number in range(1, 5):
    print(number)
~~~

출력은 1, 2, 3, 4다. 기본 형태는 `range(시작, 끝)`이고, 끝은 포함되지 않는다.

세 번째 값으로 간격을 지정할 수도 있다.

~~~python
for number in range(2, 11, 2):
    print(number)
~~~

출력은 2, 4, 6, 8, 10이다. `range(시작, 끝, 간격)`에서 간격은 기본적으로 1이다.

## 3. 반복 횟수 손으로 추적하기

아래 코드의 출력을 먼저 예상해 보자.

~~~python
for number in range(1, 4):
    print(number * 2)
~~~

| 반복 | number 값 | 출력 |
| --- | ---: | ---: |
| 1회 | 1 | 2 |
| 2회 | 2 | 4 |
| 3회 | 3 | 6 |

`range(1, 4)`의 마지막 숫자 4는 포함되지 않으므로 세 번 반복한다.

## 4. 조건이 참인 동안 반복하기: while

반복 횟수보다 조건이 언제 끝날지가 중요할 때 `while`을 사용한다.

~~~python
count = 1

while count <= 3:
    print(count)
    count = count + 1
~~~

각 단계는 다음과 같다.

1. `count <= 3`인지 확인한다.
2. 참이면 들여쓴 코드를 실행한다.
3. `count`를 1 증가시킨다.
4. 다시 조건을 확인한다.
5. 조건이 거짓이 되면 반복을 끝낸다.

이 코드는 1, 2, 3을 출력한다. `count = count + 1`은 현재 값에 1을 더해 다시 저장한다. 같은 뜻으로 `count += 1`이라고 쓸 수도 있다.

### 종료 조건이 바뀌지 않으면 생기는 일

~~~python
count = 1

while count <= 3:
    print(count)
~~~

이 코드에서는 `count`가 계속 1이라 조건이 계속 참이다. 그래서 반복이 끝나지 않는 **무한 반복**이 된다. `while`을 작성할 때는 반복 중에 종료 조건이 언젠가 거짓이 되는지 확인해야 한다.

## 5. for와 while 중 고르기

| 상황 | 보통 선택하는 반복문 |
| --- | --- |
| 목록의 모든 항목을 한 번씩 처리 | `for item in items` |
| 0부터 정해진 횟수만큼 반복 | `for number in range(...)` |
| 특정 조건이 만족될 때까지 반복 | `while condition` |

이것은 자주 쓰는 선택법이다. 처음에는 반복 횟수가 정해졌는지 또는 종료 조건을 기다리는지 살펴보면 된다.

## 6. 입력을 받아 종료하기

`while`은 사용자가 정한 값이 들어올 때까지 반복할 때도 쓸 수 있다.

~~~python
answer = ""

while answer != "끝":
    answer = input("끝이라고 입력하면 종료합니다: ")

print("반복을 마쳤어요.")
~~~

처음에는 `answer`가 빈 문자열이므로 조건이 참이고 입력을 받는다. 사용자가 "끝"을 입력하면 조건이 거짓이 되어 반복을 끝낸다.

이 예제를 실행할 때는 입력을 터미널에 해야 한다. 읽기 전용 Output 창이 아니라 **Python: Run Python File in Terminal**로 실행하고 Terminal에 답을 입력한다.

## 7. 자주 하는 실수

### range의 끝 숫자를 포함한다고 생각함

`range(1, 5)`의 값은 1, 2, 3, 4다. 5까지 반복하고 싶으면 `range(1, 6)`으로 쓴다.

### while 안에서 상태를 갱신하지 않음

조건에 사용한 변수나 조건 결과에 영향을 주는 값이 바뀌는지 확인한다. 바뀌지 않으면 무한 반복일 수 있다.

### 들여쓰기를 빼먹음

반복할 코드는 `for`나 `while` 다음 줄에서 들여쓴다. 반복문 밖 코드는 들여쓰기 깊이를 되돌린다.

### 반복 변수 이름과 목록을 혼동함

~~~python
for fruit in fruits:
    print(fruit)
~~~

`fruits`는 전체 목록이고 `fruit`는 한 번에 하나씩 가져온 값이다.
