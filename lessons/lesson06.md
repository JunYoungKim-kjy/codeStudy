# 6강 · 함수와 코드 분해

**목표:** 반복해서 사용하는 작업을 함수로 묶고, 입력·처리·결과를 분리해 읽기 쉬운 코드를 작성한다.

이번 강의는 설명을 읽은 뒤 직접 코드를 작성하는 방식으로 진행한다. 완성 코드를 그대로 복사하기보다 함수의 입력, 처리, 반환값을 먼저 말로 정리한다.

## 0. 지난 강의와 연결하기

5강에서는 한 파일 안에서 합계, 평균, 최댓값, 탐색 코드를 각각 작성했다. 같은 작업을 여러 번 하거나 코드가 길어지면 함수로 분리하는 것이 좋다.

함수는 다음 세 가지를 갖는다.

- **입력:** 함수가 작업에 사용할 값
- **처리:** 함수 안에서 수행할 작업
- **결과:** `return`으로 돌려주는 값

## 1. 함수 만들기

함수는 `def`로 만든다.

```python
def greet():
    print("안녕하세요.")

greet()
```

`def greet():`는 함수를 정의하고, `greet()`는 함수를 호출한다. 정의만 하면 함수 안의 코드는 실행되지 않는다.

## 2. 매개변수와 인자

함수에 값을 전달할 수 있다.

```python
def greet(name):
    print(f"{name}님, 안녕하세요.")

greet("민수")
```

여기서 `name`은 **매개변수**, `"민수"`는 호출할 때 전달한 **인자**다.

함수는 전달받은 값만 사용하도록 만들면 여러 상황에서 재사용할 수 있다.

## 3. `return`으로 결과 돌려주기

`print`는 화면에 보여주고, `return`은 호출한 곳으로 값을 돌려준다.

```python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)
```

`return`을 만나면 함수는 즉시 끝난다. 반환된 값은 변수에 저장하거나 다른 계산에 사용할 수 있다.

```python
def add(a, b):
    return a + b

total = add(3, 4) + add(1, 2)
print(total)
```

## 4. 출력과 반환의 차이

다음 두 함수의 목적은 다르다.

```python
def print_double(number):
    print(number * 2)

def get_double(number):
    return number * 2
```

`print_double`은 화면에 출력만 한다. `get_double`은 결과를 반환하므로 변수에 저장하거나 다시 계산할 수 있다.

```python
value = get_double(5)
print(value + 1)
```

다른 코드에서 결과를 사용해야 한다면 보통 `return`을 사용한다.

## 5. 지역 변수

함수 안에서 만든 변수는 기본적으로 함수 안에서만 사용할 수 있다.

```python
def calculate_total(numbers):
    total = 0
    for number in numbers:
        total += number
    return total
```

위 함수의 `total`은 함수 밖에서 직접 사용할 수 없다. 함수 밖에서는 반환된 결과를 변수에 저장해 사용한다.

```python
numbers = [3, 7, 2]
total = calculate_total(numbers)
print(total)
```

## 6. 기본값 매개변수

매개변수에 기본값을 지정할 수 있다.

```python
def greet(name, message="안녕하세요"):
    print(f"{name}님, {message}")

greet("민수")
greet("지영", "반가워요")
```

두 번째 인자를 생략하면 기본값이 사용된다.

## 7. 함수로 5강 코드 분리하기

5강에서 작성한 합계와 평균 코드는 각각 함수로 나눌 수 있다.

```python
def calculate_average(numbers):
    if len(numbers) == 0:
        return None

    total = 0
    for number in numbers:
        total += number
    return total / len(numbers)
```

빈 목록일 때 `None`을 반환하도록 하면, 함수를 호출한 곳에서 결과가 없는 상황을 처리할 수 있다.

함수의 책임을 작게 나누면 다음과 같은 구조가 된다.

1. 숫자 목록을 받는다.
2. 평균을 계산한다.
3. 평균 또는 `None`을 반환한다.
4. 함수 밖에서 결과를 출력한다.

## 8. 함수 작성 순서

새 함수를 만들 때는 다음 순서로 생각한다.

1. 함수가 해결할 일을 한 문장으로 쓴다.
2. 필요한 입력을 정한다.
3. 반환할 결과를 정한다.
4. 빈 입력과 잘못된 입력을 정한다.
5. 작은 예시로 실행 흐름을 확인한다.
6. 함수를 호출해 결과를 확인한다.

예를 들어 “목록에서 짝수의 개수를 반환한다”는 함수라면 입력은 숫자 목록이고, 결과는 정수 개수다. 빈 목록의 결과는 0으로 정할 수 있다.

## 9. 자주 하는 실수

### 함수를 정의하고 호출하지 않음

함수는 `def`만 작성하면 실행되지 않는다. 함수 이름 뒤에 괄호를 붙여 호출해야 한다.

### `print`한 값을 다시 사용하려고 함

다른 계산에 사용할 값이라면 `print`가 아니라 `return`으로 돌려줘야 한다.

### `return` 뒤에 코드를 작성함

`return` 뒤의 같은 함수 블록 코드는 실행되지 않는다. 반환 전에 필요한 계산을 끝내야 한다.

### 빈 목록을 함수 안에서 처리하지 않음

평균은 0으로 나눌 수 없고, 최댓값은 첫 번째 항목이 필요하다. 함수의 입력 조건과 빈 입력 결과를 먼저 정한다.

### 함수 하나가 너무 많은 일을 함

입력받기, 계산하기, 출력하기를 한 함수에 모두 넣기보다 작은 책임으로 나눈다. 처음에는 계산 함수가 값을 반환하고, 바깥 코드가 출력하도록 작성한다.

## 10. 직접 작성하는 연습 문제

아래 문제는 완성 코드를 제공하지 않는다. 함수 이름, 매개변수, 반환값을 먼저 정한 뒤 직접 작성한다.

### 문제 1 · 인사 함수

이름을 하나 받아 `"민수님, 안녕하세요."`처럼 인사 문장을 화면에 출력하는 함수를 만든다. 이름을 바꿔 두 번 호출한다.

### 문제 2 · 두 수의 큰 값

두 정수를 받아 더 큰 값을 반환하는 함수를 만든다. 두 수가 같은 경우에도 정상적으로 결과를 반환하게 한다.

### 문제 3 · 합계 함수

숫자 목록을 받아 합계를 반환하는 함수를 만든다. 빈 목록을 전달하면 0을 반환하도록 정한다.

### 문제 4 · 평균 함수

숫자 목록을 받아 평균을 반환하는 함수를 만든다. 빈 목록에서는 나누기 연산을 하지 말고 `None`을 반환한다. 함수 밖에서 `None`인지 확인해 출력 문장을 다르게 만든다.

### 문제 5 · 조건별 개수 함수

숫자 목록과 기준값을 받아 기준값 이상인 숫자의 개수를 반환하는 함수를 만든다. 예를 들어 목록 `[3, 8, 10, 1, 5]`와 기준값 `5`를 전달하면 3을 반환해야 한다.

### 문제 6 · 최댓값 함수

숫자 목록의 최댓값을 반환하는 함수를 만든다. 빈 목록에서는 `None`을 반환한다. 모든 숫자가 음수인 목록에서도 올바르게 동작해야 한다.

### 문제 7 · 탐색 함수

이름 목록과 찾을 이름을 받아, 이름이 있으면 `True`, 없으면 `False`를 반환하는 함수를 만든다. 함수 밖에서 반환값에 따라 다른 문장을 출력한다.

### 문제 8 · 함수 조합

숫자 목록을 받아 합계, 평균, 최댓값을 계산하는 세 함수를 만든다. 세 함수를 호출한 뒤 결과를 보기 좋게 출력한다. 빈 목록일 때 평균과 최댓값을 어떻게 표시할지도 정한다.
