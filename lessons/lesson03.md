# 3강 · 조건식과 분기

**목표:** 조건의 참·거짓에 따라 실행할 코드를 고를 수 있다. 비교 연산자와 논리 연산자로 조건을 만들고, 조건이 겹칠 때 순서를 정한다.

조건문은 긴 프로그램을 만들기 전에 익혀야 할 기본 도구다. 이번 강의에서는 결과를 먼저 예상하고 간단한 분류 프로그램을 직접 작성한다. 한 번에 다 이해하지 못해도 괜찮다. 문제를 작은 단계로 나눠 확인한다.

## 0. 준비: 참과 거짓

Python에서 조건식은 참인지 거짓인지 판단한다. 참은 `True`, 거짓은 `False`로 표현한다. 첫 글자는 대문자다.

~~~python
print(5 > 3)   # True
print(5 < 3)   # False
~~~

비교식 자체가 결과를 만든다. 조건문은 그 결과를 보고 어느 코드를 실행할지 결정한다.

## 1. 조건이 참일 때 실행하기

~~~python
score = 85

if score >= 60:
    print("통과")
~~~

읽는 순서는 다음과 같다.

1. `score >= 60`을 확인한다.
2. 결과가 `True`이면 들여쓴 줄을 실행한다.
3. 결과가 `False`이면 들여쓴 줄을 건너뛴다.

`if` 줄 끝에는 콜론(`:`)을 붙인다. 해당 조건에 속하는 코드는 다음 줄에서 들여쓴다. 보통 공백 4칸을 사용한다.

## 2. 비교 연산자

| 연산자 | 의미 | 예 |
| --- | --- | --- |
| `==` | 같다 | `score == 100` |
| `!=` | 다르다 | `answer != "네"` |
| `>` | 크다 | `age > 18` |
| `<` | 작다 | `temperature < 0` |
| `>=` | 크거나 같다 | `score >= 60` |
| `<=` | 작거나 같다 | `age <= 19` |

주의: `=`는 변수에 값을 넣는 대입이고, `==`는 두 값이 같은지 비교하는 연산자다.

~~~python
score = 85          # score에 85를 대입
print(score == 85)  # score가 85와 같은지 비교: True
~~~

## 3. 여러 갈래 고르기: if, elif, else

결과가 여러 갈래로 나뉘면 `elif`와 `else`를 이어서 쓴다.

~~~python
score = 85

if score >= 90:
    print("A")
elif score >= 60:
    print("통과")
else:
    print("다시 도전")
~~~

Python은 위에서 아래로 조건을 확인한다.

- `if`가 참이면 해당 코드를 실행하고 나머지 분기는 확인하지 않는다.
- `if`가 거짓이면 다음 `elif`를 확인한다.
- 앞의 조건이 모두 거짓일 때 `else`를 실행한다.
- `else`에는 조건식을 쓰지 않는다. 남은 모든 경우를 맡는다.

위 예제에서 첫 조건 `score >= 90`은 거짓이고, 다음 조건 `score >= 60`은 참이므로 `통과`가 출력된다.

## 4. 조건의 순서와 범위

조건이 겹칠 때는 더 구체적이거나 높은 기준을 먼저 확인해야 한다.

잘못된 순서:

~~~python
score = 95

if score >= 60:
    print("통과")
elif score >= 90:
    print("A")
~~~

이 코드는 `score >= 60`에서 먼저 참이 되어 `통과`를 출력한다. 그래서 `A` 분기에는 도달하지 못한다.

올바른 순서:

~~~python
score = 95

if score >= 90:
    print("A")
elif score >= 60:
    print("통과")
else:
    print("다시 도전")
~~~

점수 구간을 각각 만들고 싶다면 범위를 명확히 적을 수 있다.

~~~python
if 90 <= score <= 100:
    print("A")
elif 80 <= score < 90:
    print("B")
else:
    print("그 외")
~~~

`90 <= score < 100`처럼 비교를 이어 쓰는 문법은 Python에서 가능하다. 같은 조건은 `score >= 90 and score < 100`으로도 쓸 수 있다. 처음에는 두 방식을 읽을 수 있으면 충분하다.

## 5. 조건을 결합하기: and, or, not

조건이 둘 이상일 때 논리 연산자를 사용한다.

| 연산자 | 전체 조건이 참이 되는 경우 |
| --- | --- |
| `and` | 양쪽 조건이 모두 참 |
| `or` | 양쪽 중 하나 이상이 참 |
| `not` | 참과 거짓을 뒤집음 |

~~~python
has_ticket = True
is_adult = False

if has_ticket and is_adult:
    print("입장 가능")
else:
    print("입장 조건을 확인하세요")
~~~

`and`는 티켓이 있고 성인일 때만 참이다. `or`는 둘 중 하나만 참이어도 전체 조건이 참이다.

~~~python
is_weekend = True
is_holiday = False

if is_weekend or is_holiday:
    print("쉬는 날")
~~~

`not`은 조건의 참·거짓을 반대로 바꾼다.

~~~python
is_raining = False

if not is_raining:
    print("산책할 수 있어요")
~~~

조건을 읽을 때는 먼저 각 비교식이 참인지 확인하고, 그다음 `and`·`or`·`not`으로 묶인 전체 결과를 판단하면 된다.

## 6. 예제 추적

아래 코드를 실행하기 전에 출력 결과를 예상해 보자.

~~~python
temperature = 28
is_raining = False

if temperature >= 30:
    print("더움")
elif temperature >= 20 and not is_raining:
    print("산책하기 좋음")
else:
    print("실내 활동")
~~~

추적 과정:

1. `temperature >= 30`은 거짓이다.
2. 다음 조건에서 `temperature >= 20`은 참이고 `not is_raining`도 참이다.
3. `and` 양쪽이 모두 참이므로 `산책하기 좋음`을 출력한다.

## 7. 자주 하는 실수

### 콜론을 빠뜨림

~~~python
if score >= 60
    print("통과")
~~~

`if` 줄 끝에 콜론이 필요하다.

### 들여쓰기를 맞추지 않음

조건에 속하는 줄은 같은 깊이로 들여쓴다. 공백과 탭을 섞지 말고, VS Code에서는 보통 공백 4칸을 사용한다.

### 대입과 비교를 혼동함

`score = 60`은 값을 저장하고, `score == 60`은 같은지 비교한다.

### 조건 순서 때문에 뒤 분기에 도달하지 못함

넓은 조건을 먼저 쓰면 좁은 조건이 가려질 수 있다. 점수 구간은 높은 기준부터 검사한다.

### 경계값을 빠뜨림

`score > 60`은 60을 포함하지 않는다. 60도 통과라면 `score >= 60`이어야 한다. 경계값을 직접 넣어 확인한다.

### and와 or를 뒤바꿈

“두 조건을 모두 만족”이면 `and`, “둘 중 하나라도 만족”이면 `or`를 쓴다. 요구사항을 조건식으로 옮기기 전에 말로 다시 확인한다.

## 8. 연습 문제

먼저 결과를 손으로 예상하고, 가능하면 VS Code에서 실행해 비교한다. 답만 적지 말고 어떤 조건이 참이었는지도 설명한다.

### 문제 1 · 출력 예측

~~~python
number = 12

if number > 20:
    print("A")
elif number >= 10:
    print("B")
else:
    print("C")
~~~

무엇이 출력될까? 각 조건의 참·거짓도 적어 보자.

### 문제 2 · 경계값

다음 점수를 하나씩 대입해 결과를 판단한다.

~~~python
score = 59
score = 60
score = 89
score = 90
~~~

규칙은 60점 이상이면 통과, 90점 이상이면 우수다. 각 점수에 대해 출력할 결과를 적고, 검사 순서를 정한다.

### 문제 3 · 논리식 읽기

~~~python
age = 20
has_ticket = True

if age >= 19 and has_ticket:
    print("입장 가능")
else:
    print("입장 불가")
~~~

출력 결과를 예상한다. 그리고 `age = 17` 또는 `has_ticket = False`일 때도 각각 무엇이 출력되는지 확인한다.

### 문제 4 · 직접 작성

점수 `score`를 다음 기준으로 분류하는 조건문을 작성한다.

- 90점 이상: `A`
- 80점 이상 90점 미만: `B`
- 70점 이상 80점 미만: `C`
- 70점 미만: `다시 공부해요`

`70`, `80`, `90`을 직접 넣어 구간 경계를 확인한다.

### 문제 5 · 직접 작성

정수 `number`가 2와 3으로 모두 나누어 떨어지면 `"둘 다"`, 2로만 나누어 떨어지면 `"2로 나누어짐"`, 3으로만 나누어 떨어지면 `"3으로 나누어짐"`, 어느 쪽도 아니면 `"해당 없음"`을 출력한다.

힌트: 나머지가 0인지 확인할 때 `number % 2 == 0`처럼 쓴다. 두 조건을 모두 만족하는 경우를 먼저 검사해야 한다.
