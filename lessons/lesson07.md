# 7강 · 문자열과 순서 자료형

**목표:** 문자열과 리스트의 인덱스·슬라이싱·길이를 이해하고, 여러 값을 순서대로 다루는 함수를 작성한다.

이번 강의는 문자열과 리스트를 직접 조작하는 방식으로 진행한다. 문제는 완성 코드를 복사하지 않고, 요구사항을 읽은 뒤 직접 작성한다.

## 0. 문자열과 리스트의 공통점

문자열과 리스트는 여러 값을 순서대로 저장하는 **순서 자료형**이다.

```python
word = "python"
numbers = [10, 20, 30]
```

문자열은 문자들이 순서대로 모인 값이고, 리스트는 여러 값이 순서대로 모인 자료형이다. 둘 다 인덱스로 특정 위치에 접근할 수 있다.

## 1. 인덱스는 0부터 시작한다

```python
word = "python"

print(word[0])
print(word[1])
print(word[-1])
```

출력되는 문자는 각각 `p`, `y`, `n`이다.

리스트도 같은 방식으로 접근한다.

```python
numbers = [10, 20, 30]

print(numbers[0])
print(numbers[-1])
```

인덱스는 0부터 시작하므로 길이가 3인 자료의 인덱스는 `0, 1, 2`다.

## 2. 인덱스 범위와 오류

자료의 길이를 `len()`으로 확인할 수 있다.

```python
word = "python"
print(len(word))
```

`python`의 길이는 6이고, 사용할 수 있는 인덱스는 `0`부터 `5`까지다. `word[6]`처럼 범위를 벗어난 인덱스를 사용하면 `IndexError`가 발생한다.

접근하기 전에 인덱스가 유효한지 확인할 수 있다.

```python
def get_item(items, index):
    if index < 0 or index >= len(items):
        return None
    return items[index]
```

## 3. 슬라이싱

슬라이싱은 자료의 일부를 잘라서 가져오는 방법이다.

```python
word = "python"

print(word[0:2])
print(word[2:])
print(word[:4])
```

슬라이싱의 끝 인덱스는 포함되지 않는다.

- `word[0:2]`: 인덱스 0, 1
- `word[2:]`: 인덱스 2부터 끝까지
- `word[:4]`: 처음부터 인덱스 3까지

간격을 지정할 수도 있다.

```python
word = "abcdef"
print(word[::2])
```

위 코드는 한 칸씩 건너뛰며 `ace`를 만든다.

## 4. 문자열은 직접 수정할 수 없다

문자열은 특정 인덱스의 문자를 직접 바꿀 수 없다.

```python
word = "python"
# word[0] = "P"  # 오류
```

새 문자열을 만들어 다시 저장해야 한다.

```python
word = "python"
word = "P" + word[1:]
print(word)
```

문자열의 일부를 바꿀 때는 `replace()` 같은 문자열 메서드도 사용할 수 있다.

```python
text = "I like Java"
text = text.replace("Java", "Python")
print(text)
```

## 5. 리스트는 수정할 수 있다

리스트는 특정 위치의 값을 바꿀 수 있다.

```python
colors = ["red", "green", "blue"]
colors[1] = "yellow"
print(colors)
```

리스트에는 값을 추가·삭제할 수 있다.

```python
colors.append("black")
colors.pop()
```

- `append(value)`: 끝에 값 추가
- `pop()`: 마지막 값 삭제 후 반환
- `remove(value)`: 처음 발견한 특정 값 삭제

`remove()`로 없는 값을 삭제하면 오류가 발생할 수 있으므로, 필요한 경우 먼저 존재 여부를 확인한다.

## 6. 문자열 메서드

문자열에는 자주 사용하는 메서드가 있다.

```python
text = "  Hello Python  "

print(text.strip())
print(text.lower())
print(text.upper())
print(text.replace("Python", "World"))
```

메서드는 원본 문자열을 직접 바꾸기보다 새로운 문자열을 반환하는 경우가 많다. 결과를 저장하려면 변수에 다시 대입해야 한다.

```python
text = text.strip()
```

## 7. `in`으로 포함 여부 확인

문자열이나 리스트에 값이 있는지 `in`으로 확인할 수 있다.

```python
word = "python"
print("py" in word)

colors = ["red", "green", "blue"]
print("green" in colors)
```

문자열에서 `in`은 부분 문자열을 찾고, 리스트에서는 항목 하나를 찾는다.

## 8. 문자열과 리스트를 함수로 다루기

앞 강의에서 배운 함수와 결합하면 재사용 가능한 작업을 만들 수 있다.

```python
def count_character(text, target):
    count = 0
    for character in text:
        if character == target:
            count += 1
    return count
```

이 함수는 문자열을 받아 특정 문자의 개수를 반환한다. 출력은 함수 밖에서 담당할 수 있다.

```python
result = count_character("banana", "a")
print(result)
```

## 9. 자주 하는 실수

### 인덱스가 1부터 시작한다고 생각함

첫 번째 값은 인덱스 0이다. 길이가 `N`이면 마지막 인덱스는 `N - 1`이다.

### 슬라이싱의 끝값을 포함한다고 생각함

`items[start:end]`에서 `end`는 포함되지 않는다.

### 문자열과 리스트의 수정 가능성을 혼동함

문자열은 인덱스로 직접 수정할 수 없고, 리스트는 인덱스로 값을 수정할 수 있다.

### 메서드 결과를 저장하지 않음

`text.upper()`만 작성하면 결과를 확인하거나 저장하지 않는 한 원본 변수는 그대로다.

### 빈 문자열과 빈 리스트를 고려하지 않음

빈 자료에서 첫 번째 항목을 가져오면 오류가 난다. `len()`이나 `if items:`로 먼저 확인한다.

## 10. 직접 작성하는 연습 문제

아래 문제는 완성 코드를 제공하지 않는다. 요구사항을 읽고 함수 이름, 매개변수, 반환값을 직접 정한 뒤 작성한다.

### 문제 1 · 문자열 정보

문자열 하나를 받아 문자열의 길이와 첫 번째 문자와 마지막 문자를 반환하거나 출력하는 함수를 만든다. 빈 문자열이 들어오면 첫 번째·마지막 문자를 가져오지 않고 별도 메시지를 출력한다.

### 문제 2 · 인덱스 안전 접근

리스트와 인덱스를 받아 해당 위치의 값을 반환하는 함수를 만든다. 인덱스가 범위를 벗어나면 오류를 발생시키지 말고 `None`을 반환한다. 음수 인덱스를 허용할지 직접 결정하고 설명한다.

### 문제 3 · 문자열 뒤집기

문자열을 받아 뒤집힌 문자열을 반환하는 함수를 만든다. 예를 들어 `"python"`을 전달하면 `"nohtyp"`을 반환해야 한다. 슬라이싱을 사용해도 된다.

### 문제 4 · 특정 문자 개수

문자열과 찾을 문자를 받아 해당 문자가 몇 번 나오는지 반환하는 함수를 만든다. 대문자와 소문자를 같은 문자로 볼지 결정하고, 결정한 규칙을 코드에 반영한다.

### 문제 5 · 조건에 맞는 리스트

숫자 리스트를 받아 짝수만 들어 있는 새 리스트를 반환하는 함수를 만든다. 원래 리스트가 바뀌지 않는지 확인한다.

### 문제 6 · 리스트 항목 수정

이름 리스트와 찾을 이름과 새 이름을 받아, 찾은 이름을 새 이름으로 바꾼 새 리스트를 반환하는 함수를 만든다. 이름을 찾지 못하면 원래 목록을 그대로 반환한다.

### 문제 7 · 문장 정리

앞뒤에 공백이 있을 수 있는 문장을 받아 앞뒤 공백을 제거하고, 모든 문자를 소문자로 바꾼 결과를 반환하는 함수를 만든다. 함수 밖에서 결과를 출력한다.

### 문제 8 · 함수 조합

문자열 목록을 받아 각 문자열의 길이를 계산하고, 길이가 3 이상인 문자열만 새 리스트에 담아 반환하는 함수를 만든다. 빈 목록과 빈 문자열도 테스트한다.

## 11. 오늘 배운 내용 확인

1. 인덱스가 0부터 시작하는 이유와 마지막 인덱스를 계산하는 방법은 무엇인가?
2. `items[1:4]`에서 실제로 포함되는 인덱스는 무엇인가?
3. 문자열과 리스트의 수정 가능성은 어떻게 다른가?
4. `len()`과 `in`은 각각 어떤 문제를 해결하는가?
5. 빈 문자열이나 빈 리스트에서 첫 항목을 바로 가져오면 어떤 문제가 생기는가?
6. 문자열 메서드의 결과를 변수에 다시 저장해야 하는 경우는 언제인가?

## 통과 기준

- 인덱스와 슬라이싱의 범위를 손으로 계산한다.
- 문자열과 리스트의 차이와 수정 가능성을 설명한다.
- 인덱스 오류와 빈 자료를 안전하게 처리한다.
- 문자열·리스트 관련 함수 3개 이상을 직접 구현한다.
- 함수가 원본 자료를 수정하는지 새 자료를 반환하는지 설명한다.
