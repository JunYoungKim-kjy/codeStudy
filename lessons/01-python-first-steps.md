# 1강 · Python 문법의 첫걸음

오늘은 프로그램을 만들지 않는다. 출력, 값, 변수의 뜻을 먼저 익힌다. 예상 30~45분. 코드를 외우지 않고 한 줄씩 읽어보는 것이 목표다.

## 0. 준비

현재 컴퓨터에서는 python 명령이 동작하지 않았고 py가 가리키는 Python 3.14 경로도 실행되지 않았다. [Python 공식 Windows 다운로드](https://www.python.org/downloads/windows/)에서 설치한 뒤 새 PowerShell에서 python --version을 확인한다. 설치가 막히면 오류 문구만 보내주면 된다. 설치 전에도 아래 설명을 먼저 읽을 수 있다.

## 1. 화면에 글자 출력하기

    print("안녕하세요")
    print(3)

print는 괄호 안의 값을 화면에 보여준다. "안녕하세요"는 문자열, 3은 숫자다. 따옴표가 있으면 글자이며, 숫자 계산에는 따옴표 없는 숫자를 쓴다.

예상 결과:

    안녕하세요
    3

## 2. 계산하기

    print(2 + 3)
    print(2 * 3)

+는 더하기, *는 곱하기다. 첫 줄은 5, 둘째 줄은 6이 나온다. Python은 위에서 아래로 한 줄씩 실행한다.

## 3. 변수 이해하기

    minutes = 30
    print(minutes)

minutes는 값을 담는 이름이다. =는 오른쪽 값을 왼쪽 이름에 저장한다. 첫 줄은 30을 저장하고, 둘째 줄은 저장된 값을 출력한다.

    minutes = 30
    minutes = minutes + 10
    print(minutes)

마지막 결과는 40이다. 두 번째 줄은 기존 minutes에 10을 더한 뒤 다시 저장한다.

## 4. 오늘의 확인 문제

코드를 실행하기 전에 결과를 먼저 예상해 본다.

    study_days = 3
    minutes_per_day = 20
    print(study_days * minutes_per_day)

1. 화면에 어떤 숫자가 나올까?
2. study_days를 4로 바꾸면 어떤 숫자가 나올까?
3. "20"과 20은 무엇이 다를까?

정답이 확실하지 않아도 괜찮다. 예상한 이유를 자기 말로 적어본다. Python 설치가 끝났다면 위 세 줄을 직접 입력해 확인한다. 오늘은 별도의 과제 파일을 만들 필요가 없다.

## 나에게 보낼 것

세 문제의 예상 답과 헷갈린 부분 하나. 설치를 시도했다면 python --version 결과도 함께 보낸다. 답을 보고 다음에 변수와 자료형을 더 연습할지, 조건문으로 넘어갈지 결정하겠다.
