# 취업을 향한 학습 지도

Python 초심자와 주 7~10시간을 임시 기준으로 둔다. 첫 목표는 약 9~12개월이지만 출발점과 학습 시간에 따라 달라진다. 4주마다 완성물과 이해도를 보고 재계획한다. 처음에는 데이터 분석가와 데이터 사이언티스트에 공통인 기반을 쌓는다.

| 단계 | 예상 기간 | 핵심 내용 | 통과 기준 |
| --- | --- | --- | --- |
| 0. 준비 | 1주 | Python 실행, 편집기, 터미널, Git | 파일을 실행하고 첫 커밋을 만든다 |
| 1. Python 기초 | 6~8주 | 변수, 조건, 반복, 함수, 자료구조, 파일, 예외 | CSV 요약 프로그램을 만들고 설명한다 |
| 2. 데이터 | 6~8주 | SQL 조회·집계·JOIN, pandas, 결측치, 시각화 | 공개 데이터의 질문 3개에 근거를 들어 답한다 |
| 3. 통계·수학 | 4~6주 | 분포, 표본, 신뢰구간, 가설검정, 상관과 인과, 선형대수 직관 | 지표의 한계를 설명하고 간단한 A/B 분석을 한다 |
| 4. 머신러닝 | 8~10주 | 기준 모델, 분할, 누수, 회귀·분류, 평가와 교차 검증 | 기준 모델 대비 개선과 실패 사례를 보여준다 |
| 5. AI 확장 | 6~8주 | PyTorch, 신경망, 텍스트/LLM, 품질 평가 | AI 기능 하나의 품질과 한계를 측정한다 |
| 6. 취업 준비 | 8~12주 | 포트폴리오, SQL·Python 문제, 이력서, 면접 | 공개 프로젝트 2~3개와 직무별 지원 자료를 갖춘다 |

## 첫 4주

| 주 | 주제 | 결과물 |
| --- | --- | --- |
| 1 | 실행, 출력, 변수, 자료형, 오류 읽기 | 출력·변수 이해와 짧은 예제 |
| 2 | 조건과 반복 | 항목 분류·집계 프로그램 |
| 3 | 함수, 리스트, 딕셔너리 | 여러 기록의 요약 함수 |
| 4 | 파일, CSV, 예외, Git | CSV 요약 프로그램과 사용 설명 |

## 프로젝트 사다리

1. CSV 자동화: 항목별 합계와 오류 행 출력.
2. 데이터 분석: 공개 데이터의 질문을 정의하고 수집·정제·SQL·시각화·해석을 연결.
3. 예측 모델: 누수 없는 분할과 기준 모델을 먼저 만들고 성능과 실패 사례 기록.
4. 선택 프로젝트: 추천, 수요 예측, 텍스트 분류, LLM 평가 또는 간단한 앱 중 관심 직무에 맞게 선택.

## 운영과 취업 방향

- 매주 개념 2회, 작은 문제 2회, 복습 1회. 주말에는 프로젝트 또는 보충.
- 리뷰 기준: 정확성, 읽기 쉬움, 경계 입력, 재현 가능성, 문제 설명.
- 과제를 자기 말로 설명하지 못하면 같은 개념의 다른 문제를 푼다. 이미 아는 내용은 진단 문제로 건너뛴다.
- 매월 채용 공고 5개를 읽고 요구 기술과 프로젝트의 격차를 비교한다.
- 5개월 차에 데이터 분석가, 데이터 사이언티스트, ML/AI 엔지니어 중 1차 지원 직무를 정한다. 분석가는 SQL·지표·실험, 사이언티스트는 통계·모델 평가, 엔지니어는 소프트웨어·배포를 더 깊게 공부한다.
