# Python · 자료구조와 알고리즘 · 데이터 과학 학습 로드맵

최종 수정: 2026-11-11

## 1. 목표와 설계 기준

이 로드맵은 Python 초심자가 프로그래밍 기초를 익히고, 자료구조와 알고리즘을 직접 구현한 뒤 데이터 분석·머신러닝·AI 프로젝트를 독립적으로 수행하도록 설계한다. 기존 `docs/curriculum.md`의 AI·데이터 과학 진로 목표에, 대화에서 요청한 자료구조와 알고리즘을 공통 기초로 포함한다.

- **방향:** 공통 기초를 쌓은 뒤 실제 분석·모델링 과제를 경험하고, 데이터 분석가·데이터 사이언티스트·ML/AI 엔지니어 중 우선 방향을 정한다.
- **기간:** 달력 기준 기간은 정하지 않는다. 한 강의를 여러 번에 나누어도 되고, 이해가 확인되지 않으면 다음 강의로 넘어가지 않는다.
- **언어와 도구:** Python 중심으로 시작하고 SQL을 추가한다. 표준 라이브러리를 먼저 사용하며 pandas·scikit-learn·PyTorch는 필요한 단계에서 배운다.
- **전문성의 목표:** 개념 설명, 독립 구현, 경계 상황 점검, 복잡도 비교, 결과 재현과 전달을 할 수 있는 수준을 만든다. 자격이나 숙련을 강의 수만으로 보장하지 않고, 산출물과 설명 능력으로 확인한다.

## 2. 수업 방식과 통과 기준

각 강의는 회상 → 개념 설명 → 손으로 실행 추적 → 함께 구현 → 독립 연습 → 리뷰 순서로 진행한다. 시간을 정해 놓지 않고 필요한 만큼 연습한다.

강의 통과 기준:

- 핵심 개념을 자기 말로 설명한다.
- 대표 예제를 코드 복사 없이 다시 푼다.
- 빈 입력, 한 항목, 중복, 경계값, 미발견 등 관련 예외를 확인한다.
- 알고리즘은 시간·공간 복잡도와 자료구조 선택 이유를 설명한다.
- 학습자가 이해했다고 확인한 뒤 짧은 전이 문제를 풀고, 학습자가 다음으로 가겠다고 할 때 진도를 옮긴다.

오답이 나오면 답을 바로 주기보다 어느 단계에서 생각이 달라졌는지 찾는다. 설명이 막히면 같은 말을 반복하지 않고 작은 입력, 표, 비유, 코드 추적으로 바꾼다. 단원 후에는 누적 복습을 하며 잊은 내용은 보충한다.

### 단계 B — 자료구조와 알고리즘

#### 13강 · 알고리즘 사고와 복잡도
- **목표·개념:** 입력 크기 N, 작업량과 추가 메모리, 최선·평균·최악, `O(1)`·`O(log N)`·`O(N)`·`O(N log N)`·`O(N²)`.
- **실습:** 리스트 접근·선형 탐색·이중 반복의 비교 횟수를 세고 증가 추세를 비교한다.
- **통과 기준:** Big O를 초 단위 시간으로 오해하지 않고 큰 입력에서의 증가량을 설명한다.

#### 14강 · 선형 탐색과 루프 불변식

- **실습:** 인덱스 반환, 첫 일치와 모든 일치, 최댓값의 위치 찾기.
- **통과 기준:** 빈 목록과 중복을 정의된 방식으로 처리하고 전체를 확인해야 하는 이유를 말한다.

#### 15강 · 이진 탐색
- **목표·개념:** 정렬 전제, `left`·`right`·`mid`, 구간 반감, 종료 조건, 미발견과 삽입 위치.

- **통과 기준:** 탐색 구간이 줄어드는 규칙을 설명하고 경계 오류 없이 결과를 반환한다.

#### 16강 · 정렬의 목적과 기본 정렬

- **통과 기준:** 순환으로 인한 무한 반복을 방지하고 비가중 그래프에서 BFS의 최단 경로 성질을 설명한다.

#### 27강 · 최단 경로
- **목표·개념:** 비가중 그래프 BFS, 가중 그래프 다익스트라, 우선순위 큐, 음수 간선 주의.
- **실습:** 작은 지도에서 최단 경로와 비용을 반환하고 이전 정점을 기록한다.
- **통과 기준:** 알고리즘의 적용 조건을 구분하고 음수 가중치에서 다익스트라를 무작정 쓰지 않는다.

#### 28강 · 탐욕법
- **목표·개념:** 국소 최적과 전역 최적, 선택 규칙, 정렬 후 선택, 반례와 정확성 논증.
- **실습:** 회의실 배정과 동전 문제를 풀고 탐욕법이 실패하는 조건을 찾는다.
- **통과 기준:** 예시 통과뿐 아니라 항상 맞는 이유 또는 반례를 제시한다.

#### 29강 · 동적 계획법 기초
- **목표·개념:** 겹치는 부분 문제, 상태, 점화식, 기저값, 메모이제이션과 표 방식.
- **실습:** 피보나치·계단 오르기·최소 동전 문제를 재귀에서 저장 방식으로 개선한다.
- **통과 기준:** 상태의 의미를 문장으로 정의하고 작은 입력 표를 손으로 채운다.

#### 30강 · 동적 계획법 응용과 문제 패턴
- **목표·개념:** 1·2차원 DP, 배낭·최장 공통 부분 수열 기초, 투 포인터, 슬라이딩 윈도우, 누적 합, 이분 탐색 응용.
- **실습:** 대표 문제에 패턴을 적용하고 입력 범위에 따른 복잡도를 계산한다.
- **통과 기준:** 패턴 선택 이유, 상태·구간의 의미, 복잡도를 말한다.

#### 31강 · 종합 문제 해결
- **목표·개념:** 요구사항 정리, 작은 예제, 경계 사례, 단순 해법, 병목, 개선, 복잡도, 테스트.
- **실습:** 검색·빈도·괄호·경로·정렬 문제를 힌트 단계별로 해결한다.
- **통과 기준:** 두 문제 이상을 독립적으로 풀고 설계 선택과 실패한 접근을 설명한다.

### 단계 C — 데이터 처리와 SQL

#### 32강 · 관계형 데이터와 기본 SQL
- **목표·개념:** 행·열·테이블·기본키·외래키, `SELECT`·`FROM`·`WHERE`, 정렬, NULL.
- **실습:** 공개 또는 합성 데이터에서 조건별 조회·정렬을 수행한다.
- **통과 기준:** 결과를 먼저 정의하고 중복·NULL을 고려한다.

#### 33강 · 집계와 테이블 결합
- **목표·개념:** `GROUP BY`·`HAVING`, 집계 함수, INNER·LEFT JOIN, 서브쿼리, 기본 윈도 함수.
- **실습:** 주문·사용자 테이블에서 월별 매출과 사용자별 순위를 계산한다.
- **통과 기준:** 결합 전후 행 수, 중복, 집계 단위를 설명한다.

#### 34강 · pandas 입문
- **목표·개념:** Series·DataFrame, CSV 읽기, 선택·필터, 자료형, 집계와 벡터 연산.
- **실습:** CSV에서 요약표와 그룹별 통계를 만든다.
- **통과 기준:** 인덱스·열·행을 구분하고 벡터 연산을 설명한다.

#### 35강 · 데이터 품질과 정리
- **목표·개념:** 결측·중복·형 변환·이상값·범주 표준화·날짜·단위·원본 보존.
- **실습:** 오류가 있는 표를 정리하고 행 수와 처리 규칙을 기록한다.
- **통과 기준:** 삭제·대체 선택이 결과에 미치는 영향을 설명한다.

#### 36강 · 탐색적 분석과 시각화
- **목표·개념:** 분포·비교·추세·관계, 그래프 선택, 축·단위·표본·이상치.
- **실습:** 공개 데이터에 질문 세 개를 만들고 근거 그래프와 해석을 작성한다.
- **통과 기준:** 관찰과 추론을 구분하고 그래프가 뒷받침하지 않는 결론을 피한다.

### 단계 D — 통계·수학과 실험

#### 37강 · 확률과 기술 통계
- **목표·개념:** 사건·확률, 조건부 확률의 직관, 평균·중앙값·분산·표준편차, 표본·모집단.
- **실습:** 치우친 분포와 이상값에서 평균과 중앙값을 비교한다.
- **통과 기준:** 평균 하나로 충분하지 않은 사례와 표본 한계를 말한다.

#### 38강 · 추론 통계와 A/B 테스트
- **목표·개념:** 표집 변동, 신뢰구간, 가설검정, p값의 의미와 오해, 효과 크기, 검정력, 다중 비교.
- **실습:** 실험 결과에서 통계적 유의성과 실무적 의미를 구분한다.
- **통과 기준:** 인과 주장을 위한 실험 조건과 결과 한계를 설명한다.

#### 39강 · 머신러닝에 필요한 수학
- **목표·개념:** 벡터·행렬·내적, 함수·기울기·미분의 직관, 거리·유사도, 로그·지수.
- **실습:** 작은 벡터 연산과 손실 함수 변화를 Python으로 해석한다.
- **통과 기준:** 기호를 암기하기보다 모델에서 각 값이 뜻하는 바를 말한다.

### 단계 E — 머신러닝과 AI

#### 40강 · 학습 흐름과 검증
- **목표·개념:** 지도·비지도 학습, train/validation/test, 데이터 누수, 기준선, 재현성.
- **실습:** 분할 전략과 기준 성능을 만들고 누수 사례를 찾는다.
- **통과 기준:** 테스트 데이터를 모델 선택에 사용하지 않는 이유와 지표 선택 근거를 설명한다.

#### 41강 · 회귀
- **목표·개념:** 선형 회귀, 손실, MAE·MSE·RMSE, 기준선, 잔차, 정규화 직관.
- **실습:** 공개 데이터에서 기준선과 회귀 모델을 비교하고 잔차를 분석한다.
- **통과 기준:** 평균 오차뿐 아니라 오차 분포와 예측 범위를 설명한다.

#### 42강 · 분류와 임계값
- **목표·개념:** 로지스틱 회귀 직관, 혼동 행렬, precision·recall·F1, ROC-AUC, 클래스 불균형.
- **실습:** 오탐·미탐 비용을 비교해 예측 임계값을 조정한다.
- **통과 기준:** 정확도만으로 부족한 사례를 들고 목적에 맞는 지표를 고른다.

#### 43강 · 트리 모델과 앙상블
- **목표·개념:** 결정 트리, 과적합·가지치기, 랜덤 포레스트, 부스팅, 특성 중요도의 한계.
- **실습:** 단순 모델과 앙상블을 같은 검증 방식으로 비교한다.
- **통과 기준:** 성능·복잡도·해석 가능성·데이터 크기를 함께 고려한다.

#### 44강 · 비지도 학습
- **목표·개념:** 군집화, 거리 척도, 스케일링, K-means, PCA 직관, 군집 평가의 어려움.
- **실습:** 표준화 전후 군집을 비교하고 결과의 실제 의미를 검토한다.
- **통과 기준:** 군집 번호를 정답 범주로 오해하지 않는다.

#### 45강 · 신경망과 PyTorch
- **목표·개념:** 텐서, 층·활성화, 순전파·손실·역전파, 옵티마이저, epoch·batch, 과적합.
- **실습:** 작은 분류 모델의 학습·검증 손실을 기록하고 설정을 비교한다.
- **통과 기준:** 학습 과정을 설명하고 설정을 저장해 재현한다.

#### 46강 · 텍스트·임베딩·Transformer
- **목표·개념:** 토큰화, 임베딩, 문맥, attention 직관, 사전학습·미세조정, 토큰 한계.
- **실습:** 문장 유사도 또는 간단한 텍스트 분류를 수행하고 오류를 확인한다.
- **통과 기준:** 임베딩과 모델 출력의 한계를 예로 설명한다.

#### 47강 · LLM 앱과 검색 증강 생성
- **목표·개념:** 프롬프트, 컨텍스트 창, 임베딩 검색, chunking, RAG, 근거성·환각, 개인정보.
- **실습:** 작은 문서 질의응답을 만들고 검색 실패와 잘못된 답을 평가표에 기록한다.
- **통과 기준:** 한 번의 인상적인 답이 아니라 대표 질문 집합으로 품질을 측정한다.

### 단계 F — 실무와 포트폴리오

#### 48강 · 재현성·배포·모니터링
- **목표·개념:** 의존성 고정, 데이터 버전, 스크립트·API, 로그, 데이터 드리프트, 개인정보 최소화.
- **실습:** 새 환경에서 파이프라인을 재현하고 입력 오류·실패 로그를 처리한다.
- **통과 기준:** 운영 시 감시 항목과 문제 대응을 설명한다.

#### 49강 · 분석 포트폴리오
- **목표:** 실제 질문을 정의하고 원자료에서 결론까지 완결된 분석을 만든다.
- **포함:** 데이터 출처·라이선스, 질문·지표, 정제, SQL/Python, 시각화, 해석·한계.
- **산출물:** 실행 가능한 코드, README, 핵심 발견, 가정·한계, 다음 분석 제안.
- **통과 기준:** 제3자가 실행·검증할 수 있고 질문과 방법의 연결을 설명한다.

#### 50강 · 머신러닝 또는 AI 캡스톤
- **목표:** 기준선부터 평가·실패 분석까지 포함한 모델 프로젝트를 완성한다.
- **포함:** 문제 설정, 분할·누수 방지, 기준 모델, 실험 기록, 오류 분석, 한계와 영향.
- **산출물:** 재현 가능한 저장소, 모델 설명, 지표·실패 예시, 데모 또는 추론 스크립트.
- **통과 기준:** 점수뿐 아니라 설계 선택·한계·운영 위험을 설명하고 제3자가 재현한다.

#### 51강 · 진로별 심화와 면접
- **데이터 분석가:** SQL·지표·실험·시각화·제품 및 비즈니스 의사결정.
- **데이터 사이언티스트:** 통계·모델 평가·불확실성·도메인 연구.
- **ML/AI 엔지니어:** 소프트웨어 설계·알고리즘·배포·파이프라인·관측 가능성.
- **통과 기준:** 실제 채용 공고와 포트폴리오 증거를 비교해 부족한 역량과 다음 학습 계획을 제시한다.

## 5. 공통 기초 뒤의 진로 분기

공통 기초와 분석·모델 경험을 얻은 뒤 선택한다. 그전에는 한 역할에 과도하게 특화하지 않는다.

- **데이터 분석가:** SQL·통계·실험·지표·시각화·의사소통을 심화한다.
- **데이터 사이언티스트:** 통계·실험 설계·모델 검증·도메인 지식을 심화한다.
- **ML/AI 엔지니어:** Python 설계·테스트·알고리즘·배포·데이터 파이프라인을 심화한다.

진로 분기 때 실제 공고 여러 개를 비교해 요구 기술과 현재 포트폴리오의 차이를 확인한다.

## 6. 평가와 누적 산출물

평가는 개념 설명, 독립 구현, 경계 상황 테스트, 복잡도 분석, 재현 가능한 기록의 다섯 축으로 한다.

누적 포트폴리오:
1. Python CSV 요약·검증 도구.
2. 자료구조·알고리즘 구현과 테스트 저장소.
3. SQL·Python 공개 데이터 분석 프로젝트.
4. 기준선·오류 분석을 포함한 머신러닝 프로젝트.
5. 목표 직무에 맞춘 최종 분석 또는 AI 프로젝트.

## 7. 교육 원칙

- 먼저 학습자의 시도를 받고, 막히면 정답보다 단계별 힌트를 준다.
- 질문은 현재 강의와 앞서 배운 개념에 연결해 답한다.
- 이해가 안 되면 작은 입력·다른 비유·표·실행 추적으로 다시 설명한다.
- 학습자가 이해했다고 말하면 짧은 전이 문제로 확인하고, 다음으로 가겠다고 할 때 진도를 이동한다.
- 오답은 능력 판단이 아니라 보충할 지점을 찾는 자료로 사용한다.
- 도구 설정이 학습 목표를 가리지 않도록 작은 결과물을 단계별로 만든다.
