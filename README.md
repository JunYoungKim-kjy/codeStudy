# 퇴근 후 AI·데이터 과학 공부

시작일: 2026-11-10. 목표는 Python으로 데이터를 다루고 SQL·통계·머신러닝을 활용해 문제를 풀며, 그 과정을 설명할 수 있는 포트폴리오를 만드는 것이다. 진도는 기간보다 실제 결과물과 이해도로 조정한다.

## 수업 방식

- 임시 시간표: 평일 하루 60~90분씩 5일, 주말 2~3시간 프로젝트. 힘든 날은 20분 복습. 첫 주 이후 조정.
- 매 수업: 지난 과제 점검 10분 → 새 개념 20분 → 직접 코딩 30~45분 → 설명과 기록 10분.
- 학생이 먼저 시도한다. 나는 단계별 힌트, 코드 리뷰, 오류 분석, 재설명, 진도 조정을 맡는다.
- AI 도움을 받기 전에 첫 시도는 직접 작성하고, 도움받은 부분을 기록한다.
- 매주 작은 완성물을 Git에 남긴다. 프로젝트에는 문제, 데이터 출처, 실행 방법, 해석, 한계를 적는다.

## 오늘 할 일

1. [첫 수업](lessons/01-python-first-steps.md)을 읽고 Python 실행 환경을 확인한다.
2. 출력·변수 설명을 읽고 세 가지 확인 문제의 답을 예상한다. 첫날에는 과제 파일을 만들지 않는다.
3. 예상 답과 헷갈린 점을 이 대화에 보낸다. 내가 설명한 뒤 다음 수업을 진행한다.
4. [학습 기록](docs/progress.md)에 공부 시간과 막힌 점을 적는다.

## GitHub

이 폴더는 로컬 Git 저장소다. GitHub의 빈 저장소를 만든 뒤 원격 주소를 연결한다. 첫 실습 이후 커밋한다. 개인 정보, API 키, 비공개 데이터, 가상환경은 올리지 않는다.
